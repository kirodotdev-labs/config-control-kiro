# Config Control for Kiro 3.0

**Built for Kiro CLI V3.** Config Control 3.0 is rebuilt around Kiro CLI V3: every setting V3 uses, shown in plain forms right next to the real file, with a Terminal button on every page to try what you set up.

> **Updating from 1.x:** download 3.0 once by hand (links below) and replace the app you have. From 3.0 on, the app updates itself.

## What's new

### Built for Kiro CLI V3
- **Every V3 setting in one place,** for Global and for each project Workspace: agents, MCP servers, permissions, sandbox, hooks, steering, skills, prompts, workflows, specs, code intelligence, powers, memory, settings and ACP.
- **Form and file side by side.** Each page shows a form next to the real file (JSON, YAML or Markdown). Change either and the other follows. Settings the app doesn't know are kept exactly as they are.
- **Kiro's own words.** Pages use Kiro's terms (capability, effect, match, inclusion, preset…), so what you learn here matches Kiro's docs.
- **Try it right away.** A Terminal button on every page opens a Kiro chat and tells you exactly what to type.

### Agents
- A form for every part of an agent: prompt, model and effort, tools, MCP servers, permissions, context, knowledge, hooks, sub-agents and powers.
- **Upgrade older agents to V3** with Kiro's own upgrade: see Kiro's verdict for each agent, preview the result, upgrade one or all, and restore from the backup.

### Permissions and the sandbox
- **Permission rules as cards** in Kiro's terms (capability, effect, match, exclude), with suggestions, presets (including approve-for-me) and the YAML beside them.
- **Sandbox** on one page, with the permission rules it follows (hosts it may reach, paths it may use) and how to check it's working.

### Steering, skills, prompts and memory
- **Steering** with Kiro's inclusion modes explained, and which agents see each file.
- **Skills as folders:** edit SKILL.md in a form, add scripts, references and assets (new, or copied from your computer), and import skills from GitHub or a folder.
- **Prompts** with an Arguments bar and the exact `/name` command to run.
- **Memory:** see everything Kiro remembers, add your own memories, edit and delete them (Kiro saves the changes), and choose how Kiro may use memory.

### Powers
- Browse Kiro's catalog, install from the catalog, GitHub or a folder, and reinstall to get the latest.
- **Open any power** to see and edit its manifest, MCP servers, steering, skills and files on one page.
- **Build your own power** from a starting layout, then install and test it.

### Plan and build
- **Specs** (per project): feature specs (requirements first or design first), bugfix specs, quick specs and plan mode, each explained. Start a spec, tick tasks, and have Kiro write the next document, rewrite one, update what follows an edit, or run any task again.
- **Workflows:** turn workflows on, start from templates, edit recipes as a graph, and follow each run step by step.
- **Code intelligence** (per project): see the languages in your project and which language servers are installed (with the install command for your computer), and set them up in one click.

### Chats and usage
- Every Kiro chat with its credits and context use, your plan and its reset date, tags you can search, running chats that update live, and resume or delete through Kiro.

### Automatic updates
- The app updates itself in the background and installs the update when you're not using it, then reopens where you were.
- Every update is checked against our signature before it's installed. A version that doesn't start is rolled back automatically.
- The **Update** button next to the version shows the status, and switches automatic updates off if you prefer.

### Improvements
- Works on Windows, macOS (Intel and Apple Silicon), Linux and WSL, with commands and install steps for your system.
- Unsaved changes are protected, and Ctrl/Cmd+S saves.
- A clearer navigator: each project's items in one tree, with lines showing which agent uses which file.
